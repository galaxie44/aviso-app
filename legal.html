Mentions légales

L'application AVISO est mise à disposition pour un usage professionnel par une collectivité territoriale. Les données de planification sont stockées localement sur l'appareil. Le site et les APK peuvent être hébergés via GitHub Pages / Releases.

Contact modèle : dpo@mairie.example.fr — à remplacer.

CGU (extrait)

AVISO permet de programmer des messages WhatsApp. L'utilisateur habilité s'engage à un usage légitime, proportionné, conforme au droit et aux règles internes. AVISO n'est pas un produit Meta et n'utilise pas l'API Cloud officielle dans sa version locale gratuite.

Droit applicable : droit français.

Confidentialité / RGPD (extrait)

Responsable de traitement : la collectivité utilisatrice. Données typiques : contacts (nom, téléphone), contenus programmés, statuts d'envoi. Finalité : communications institutionnelles. Conservation : jusqu'à suppression / désinstallation, sauf politique interne plus stricte.

Droits CNIL : accès, rectification, effacement, limitation, opposition, réclamation sur cnil.fr.

Cookies

L'app n'utilise pas de cookies publicitaires. Le site peut être servi par GitHub Pages (traceurs techniques éventuels de l'hébergeur).

Avertissement WhatsApp

L'automatisation peut enfreindre les conditions Meta selon l'usage. Validation DPO / juridique recommandée avant diffusion citoyenne massive.
